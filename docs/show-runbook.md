# 演出操作手冊（12/03）

一頁版。**任何會讓鴨子動的步驟，旁邊都要有人能扶。**

## 演出用的做法（11/25 定案）
- **不用標記跟隨，改成直線走**（腳本模式）：鴨子看不清楚 ArUco 標記，所以上台、下台都走固定直線。
  - "Let's go" 或 `f`：**直走 2 公尺**上台（`--walk-m` 可改）。
  - "Let's go home" 或 `h`：**原地轉 180°，再直走 2 公尺**回來。
- **語音由筆電辨識**：鴨子的麥克風收音，透過 Wi-Fi 傳給筆電辨識，再把指令送回鴨子。**筆電要在現場，而且要跟鴨子連在同一個 Wi-Fi。**
- **不開相機**：CPU 比較涼，也不用停 mediad，不用 sudo 密碼。

## 前一天
- [ ] **電池充飽**：開機時要 **8 V 以上**（滿電約 8.4 V）。兩顆電池都只充到 7.8–7.9 V 的話，先檢查充電器。
- [ ] 筆電：SSH 金鑰可用（`ssh radxa@<IP> hostname` 不用密碼）、WSL 裡有語音模型（`~/mdev/asr/…kroko…`）。
- [ ] 排練一次完整流程，量直走 2 公尺實際走多遠、要多久。

## 上台前（約 15 分鐘）
1. **扶著鴨子開機**。坐著開機時 robotd 可能自己站起來，手要先扶好。
2. 讀狀態：`ssh -o HostKeyAlias=192.168.50.135 radxa@192.168.50.237 robotctl health`
   - 電池 **> 7.0 V** 才能開演（低於 7.5 V 會提醒盡快充電）。
   - 如果出現 `no robot on the motor bus` 或 `out of single-turn range`：關機、**拔電池 10 秒**、鴨子擺正坐好、再開機。
3. **一個指令開演**（在筆電的 PowerShell）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\Microduck-Project\follow\start_show.ps1
   ```
   - 會多開一個「DUCK EARS」視窗（筆電語音）。它會自己等 show 開好再接上，斷線也會自己重連。
   - 原本的視窗會跑 show：按 Enter → **扶好鴨子再輸入 `yes`**。
   - 只用鍵盤：加 `-NoEars`。要改直走距離：加 `-WalkM 1.5`。
4. 鴨子還坐著或是 `held`：在 show 視窗打 `u` 站起來。**起身時可能晃一下、腿軟一下再站好**（見下方「已知問題」），手護著就好，不要抓住。
5. 試一次：說 **"Say hello"**，鴨子會轉頭、叫一聲。

## 老闆的流程
| 步驟 | 老闆說 | 操作員備援 | 鴨子 |
|---|---|---|---|
| 1. 上台 | **"Let's go!"**（或 "Let's go, follow me!"） | 沒反應就按 `f` | 直走 2 公尺 |
| 2. 撒錢槍 | **"Let's party!"**（或 "Shake it"） | 沒反應就按 `d` | 原地跳舞，最多 30 秒 |
| 3. 下台 | **"Let's go home"**（或再說一次 "Let's go"） | 沒反應就按 `h` | 轉 180° 後直走 2 公尺 |

- **"Let's go" 一詞兩用**：還沒上台時 = 上台；已經上台後 = 回家。
- 筆電語音聽到指令時，DUCK EARS 視窗會印 `✓ '…' → dance` 這樣的一行，操作員看得到有沒有聽到。
- 直走速度約 0.07 m/s 實際前進（指令 0.12 m/s），**2 公尺大約 30 秒**；odom 量不準時，35 秒一到也會停。
- 鴨子聽到指令會叫一聲回應；聽到但不能照做會發出疑問聲。

## 全部指令
| 說 | 鍵盤 | 鴨子做什麼 |
|---|---|---|
| "Let's go" | — | 上台前 = 直走上台；上台後 = 回家 |
| "Follow me" | `f` | 直走上台（腳本模式） |
| "Let's go home" / "Go home" | `h` | 轉 180° 再直走回來 |
| "Let's party" / "Shake it" | `d` | 原地跳舞，最多 30 秒 |
| "Say hello" | `w` | 轉頭、張嘴、叫一聲 |
| "Look at me" | `g` | 只轉頭（腳本模式沒有相機，所以不會追人） |
| "Sit down" | `x` | 坐下 |
| "Get up" | `u` | 站起來 |
| "Lie down" | `p` | 蹲低前傾（「趴下」） |
| "Stop" | `s` 或 **Enter** | 停下、站著。**緊急時按 Enter 最快** |
| — | `k` | 直走 2 公尺（不管上台與否） |
| — | `q` | 結束程式，鴨子站著 |

## 安全門檻（11/25 使用者決定）
| 項目 | 門檻 |
|---|---|
| 電池 | **7.0 V** 停止走路、起身、開演（原廠建議 7.5 V；6.6 V 以下會傷電池，不能再低） |
| CPU | 90 °C 自動回待命 |
| 馬達 | 65 °C；**左髖（left_hip_roll）80 °C**（它的讀數偏高，摸起來不燙，show.sh 預設放寬） |

## 已知問題
- **坐姿起身容易晃倒**：起身剛結束的瞬間，robotd 的「跌倒軟著陸」會把晃動誤判成跌倒，讓腿軟一下再擺回站姿。電池滿、馬達涼的時候比較少發生。要根治得調 robotd 的跌倒設定（違反 CLAUDE.md 第 3 條，要使用者同意）。
- **直走一起步就停（11/25 下午）**：`f`／`k` 試了 3 次，每次程式都印「倒地或卸力」並回到待命，鴨子沒走出去。原因還在查，查清楚前上台、下台先準備好由人抱鴨子的備案。
- **關機前一定先坐下**（`x`）。站著關機會軟倒，11/24 因此讓左髖的圈數計數出錯，要拔電池才恢復。

## 緊急狀況
| 狀況 | 做什麼 |
|---|---|
| 走錯方向、太靠近台邊 | 按 **Enter**（或 `s`），或喊 "Stop" |
| 程式沒反應 | `Ctrl-C`：程式會送 stop，鴨子站著 |
| 還是在動 | 扶住鴨子，另開 SSH：`sudo systemctl stop robotd`（**鴨子會卸力倒下，一定要先扶住**） |
| 連不上 SSH | 扶住，關電源 |
| 倒地 | 扶好後在 show 視窗按 `u` 站起來，站穩後再下指令 |
| 語音沒反應 | 看 DUCK EARS 視窗有沒有印出聽到的字；沒有就用鍵盤 |

## 結束後
1. show 視窗打 `x` 讓鴨子**坐下**，再打 `q` 結束。
2. 關機：`sudo poweroff`（密碼由操作員自己輸入），等關機完成再斷電。

## 備案：標記跟隨（相機）
`start_show.ps1 -Camera`：改回 ArUco 標記跟隨（要停 mediad、要 sudo）。標記要印大張（A4 印滿），手機螢幕在暗處太亮會認不到。
