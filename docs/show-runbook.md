# 演出操作手冊（12/03）

一頁版。**任何會讓鴨子動的步驟，旁邊都要有人能扶。**

## 演出用的做法（11/25 定案）
- **不用標記跟隨，改成直線走**（腳本模式）：鴨子看不清楚 ArUco 標記，所以上台、下台都走固定直線。
  - "Let's go" 或 `f`：**直走 2 公尺**上台（`--walk-m` 可改）。
  - "Let's go home" 或 `h`：**原地轉 180°，再直走 2 公尺**回來。
- **語音由筆電辨識**：鴨子的麥克風收音，透過 Wi-Fi 傳給筆電辨識，再把指令送回鴨子。**筆電要在現場，而且要跟鴨子連在同一個 Wi-Fi。**
- **不開相機**：CPU 比較涼，也不用停 mediad，不用 sudo 密碼。

## 前一天
- [ ] **電池充飽**：開機時要 **8 V 以上**（滿電約 8.4 V）。兩顆電池都只充到 7.8–7.9 V 的話，先檢查充電器。
- [ ] 筆電：SSH 金鑰可用（`ssh radxa@<IP> hostname` 不用密碼）、WSL 裡有語音模型（`~/mdev/asr/…kroko…`）。
- [ ] 排練一次完整流程，量直走 2 公尺實際走多遠、要多久。

## 上台前（約 15 分鐘）
1. **扶著鴨子開機**。坐著開機時 robotd 可能自己站起來，手要先扶好。
2. 讀狀態：`ssh -o HostKeyAlias=192.168.50.135 radxa@192.168.50.237 robotctl health`
   - 電池 **> 7.0 V** 才能開演（低於 7.5 V 會提醒盡快充電）。
   - 如果出現 `no robot on the motor bus` 或 `out of single-turn range`：關機、**拔電池 10 秒**、鴨子擺正坐好、再開機。
3. **一個指令開演**（在筆電的 PowerShell；開了「開機待命」也是同一個指令，會直接打開操作台）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\Microduck-Project\follow\start_show.ps1
   ```
   - 會多開一個「DUCK EARS」視窗（筆電語音）。它會自己等 show 開好再接上，斷線也會自己重連。
   - 原本的視窗會跑 show：按 Enter → **扶好鴨子再輸入 `yes`**。
   - 開機待命（`standby_install.sh`）時沒有 Enter 那一步：視窗直接是操作台，**扶好鴨子再輸入 `yes`**。之後操作台或 DUCK EARS 斷線，鴨子會自己停下，重新連上再下指令。
   - 只用鍵盤：加 `-NoEars`。要改直走距離：加 `-WalkM 1.5`。
4. 鴨子還坐著或是 `held`：在 show 視窗打 `u` 站起來。**起身時可能晃一下、腿軟一下再站好**（見下方「已知問題」），手護著就好，不要抓住。
5. 試一次：說 **"Say hello"**，鴨子會轉頭、叫一聲。

## 只用手機（手機開熱點＋手機 SSH 按鍵，不帶筆電）
前提：鴨子已部署並開了「開機待命」（`bash ~/microduck-follow/current/follow/standby_install.sh`）。
**沒有筆電就沒有語音**（語音是筆電辨識的），全部用按鍵。
1. 手機熱點名稱 `MOHENG`（設定方式見 Wi-Fi 那節），**扶著鴨子開機**，等 1～3 分鐘。show 會自己在背景待命，鴨子坐著不動。
2. 手機 SSH App（例如 Termius）新增主機：位址 `radxa.local`（不行就用鴨子的 IP）、使用者 `radxa`。
   - 在那台主機的「開機指令／Startup snippet」填：`bash ~/microduck-follow/current/follow/console.sh`，以後一連上就直接進操作台。
   - 沒設的話，連上後自己打這行也一樣。
3. 進了操作台：**扶好鴨子 → 打 `yes` 按 Enter** 解鎖。之後**直接按字母，不用 Enter**：
   `u` 站起、`f` 上台、`d` 跳舞、`h` 回家、`x` 坐下，**空白鍵或 Enter = 停**。
4. **手機 App 要一直開在前景、螢幕不要鎖**：連線一斷鴨子就會停下（安全設計）。重新連上、再打一次 `yes` 就能繼續。
5. 結束（照順序）：
   1. 按 `x`，讓鴨子**坐下**，等它坐好（站著關機會軟倒）。
   2. 按大寫 **`Q`**（Shift＋q），結束 show。
   3. 在同一個 SSH 裡打 **`sudo poweroff`** 按 Enter，再輸入密碼（自己輸入）。
   4. SSH 斷線後再等約 30 秒，完全關機了才關電源開關或拔電池。
   - 手機連不上鴨子時：扶好、讓它坐著，直接關電源開關。

## 老闆的流程
| 步驟 | 老闆說 | 操作員備援 | 鴨子 |
|---|---|---|---|
| 1. 上台 | **"Let's go!"**（或 "Let's go, follow me!"） | 沒反應就按 `f` | 直走 2 公尺 |
| 2. 撒錢槍 | **"Let's party!"**（或 "Shake it"） | 沒反應就按 `d` | 原地跳舞，最多 30 秒 |
| 3. 下台 | **"Let's go home"**（或再說一次 "Let's go"） | 沒反應就按 `h` | 轉 180° 後直走 2 公尺 |

- **"Let's go" 一詞兩用**：還沒上台時 = 上台；已經上台後 = 回家。
- 筆電語音聽到指令時，DUCK EARS 視窗會印 `✓ '…' → dance` 這樣的一行，操作員看得到有沒有聽到。
- 直走速度約 0.07 m/s 實際前進（指令 0.12 m/s），**2 公尺大約 30 秒**；odom 量不準時，35 秒一到也會停。
- 鴨子聽到指令會叫一聲回應；聽到但不能照做會發出疑問聲。

## 全部指令
| 說 | 鍵盤 | 鴨子做什麼 |
|---|---|---|
| "Let's go" | — | 上台前 = 直走上台；上台後 = 回家 |
| "Follow me" | `f` | 直走上台（腳本模式） |
| "Let's go home" / "Go home" | `h` | 轉 180° 再直走回來 |
| "Let's party" / "Shake it" | `d` | 原地跳舞，最多 30 秒 |
| "Say hello" | `w` | 轉頭、張嘴、叫一聲 |
| "Look at me" | `g` | 只轉頭（腳本模式沒有相機，所以不會追人） |
| "Sit down" | `x` | 坐下 |
| "Get up" | `u` | 站起來 |
| "Lie down" | `p` | 蹲低前傾（「趴下」） |
| "Stop" | `s` 或 **Enter** | 停下、站著。**緊急時按 Enter 最快** |
| — | `k` | 直走 2 公尺（不管上台與否） |
| — | `q` | 結束程式，鴨子站著 |

## 安全門檻（11/25 使用者決定）
| 項目 | 門檻 |
|---|---|
| 電池 | **7.0 V** 停止走路、起身、開演（原廠建議 7.5 V；6.6 V 以下會傷電池，不能再低） |
| CPU | 90 °C 自動回待命 |
| 馬達 | 65 °C；**左髖（left_hip_roll）80 °C**（它的讀數偏高，摸起來不燙，show.sh 預設放寬） |

## 起身規則（11/26）
- **整場只起身一次**：上台前在後台、**雙手護著**按 `u`（從地上要 3 秒內按兩次），看到「站穩了」才放手。
- **演出中不要按 `x` 坐下**，結束才坐。每次坐姿起身都可能晃倒。
- 電池 **8 V 以上**再起身，晃得比較少。

## 已知問題
- **坐姿起身容易晃倒**：起身動作結束後約 0.3 秒，身體還前傾約 45°，robotd 的「跌倒軟著陸」（`limp_fall`）把它當成跌倒，腿先軟下來再擺回站姿，有時就真的倒了。使用者同意演出期間把 `/etc/robot/robotd.toml` 的 `limp_fall` 關掉（見下方「robotd 設定」），**11/26 還沒套用**（腳本 `/tmp/limpfall_off.sh` 已備好，要 sudo 密碼並重啟 robotd）。關掉後真的跌倒時會硬著地，所以旁邊一定要有人護著。
- **轉 180° 改成定時（11/26）**：odom 航向太吵，閉迴路轉身每次 2 秒內就自己放棄。腳本模式的 `h` 改成以 0.4 rad/s 轉固定秒數（預設約 8.7 秒，`STANDBY_TURN_S` 或 `--turn-seconds` 可調），轉不夠或轉過頭就調秒數。
- **走一走整台斷電（11/26 晚上）**：直走起步時主機板燈全暗，原因是**排線掉了**（走路晃動拉鬆）。接回後正常開機。接排線前一定要斷電、插到底並扣上鎖扣、把線固定在機身上，別讓關節夾到或拉到。下午從地上起身時整台重開，可能也是同一條排線半鬆。
- **直走一起步就停（11/25 下午）**：原因是坐姿起身後的跌倒誤判（同上），11/26 已修（站穩 3 秒才算起身完成）。

## robotd 設定（演出用，演出後改回；11/26 尚未套用）
- 檔案 `/etc/robot/robotd.toml`，`[safety]` 段加 `limp_fall = false`。改完要 `sudo systemctl restart robotd`（**鴨子會卸力，先扶好、讓它坐著**）。
- 改回：刪掉那一行（備份在 `/etc/robot/robotd.toml.bak-1126`），再重啟 robotd。
- **關機前一定先坐下**（`x`）。站著關機會軟倒，11/24 因此讓左髖的圈數計數出錯，要拔電池才恢復。

## 緊急狀況
| 狀況 | 做什麼 |
|---|---|
| 走錯方向、太靠近台邊 | 按 **Enter**（或 `s`），或喊 "Stop" |
| 程式沒反應 | `Ctrl-C`：程式會送 stop，鴨子站著 |
| 還是在動 | 扶住鴨子，另開 SSH：`sudo systemctl stop robotd`（**鴨子會卸力倒下，一定要先扶住**） |
| 連不上 SSH | 扶住，關電源 |
| 倒地 | 扶好後在 show 視窗按 `u` 站起來，站穩後再下指令 |
| 語音沒反應 | 看 DUCK EARS 視窗有沒有印出聽到的字；沒有就用鍵盤 |

## 結束後
1. show 視窗打 `x` 讓鴨子**坐下**，再打 `q` 結束。
2. 關機：`sudo poweroff`（密碼由操作員自己輸入），等關機完成再斷電。
