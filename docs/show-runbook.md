# 演出操作手冊（12/03）

一頁版。詳細說明在 `follow/README.md`。**任何會讓鴨子動的步驟，旁邊都要有人能扶。**

## 前一天
- [ ] 充飽電（滿電約 8.4 V；follow 低於 7.6 V 就不走）。
- [ ] 主持人的 ArUco marker：DICT_5X5_50、**ID 0**，黑框 120–150 mm，平整不反光，**胸前和背後各貼一張**（下台時老闆背對鴨子）。
- [ ] 排練一次完整流程，記下 CPU 溫度與電壓變化。
- [ ] 筆電：SSH 金鑰可用（`ssh radxa@<IP> hostname` 不用密碼）。

## 上台前（約 15 分鐘）
1. **扶著鴨子**開機。坐著開機時 robotd 會**自己站起來**（sitstand），手要先扶好。
2. 筆電連同一個 Wi-Fi，確認 IP（變了就到路由器／熱點列表找 `radxa`）：
   ```bash
   ssh radxa@<IP>
   ```
3. 如果鴨子是 `held`（站著但策略沒控制）或坐著：扶好後 `cd ~/microduck-follow/current && python3 -m follow.stand`（會問 yes）。
4. **一個指令開演**（唯讀檢查 → sudo 停 mediad → 啟動 follow；結束時自動恢復 mediad）：
   ```bash
   bash ~/microduck-follow/current/follow/show.sh
   ```
   - 電池 < 7.6 V 會直接拒絕。
   - 會先印電池／CPU／閘門狀態，按 Enter 後要輸入 sudo 密碼（操作員自己輸入），follow 啟動後會再問一次 yes：**扶好再輸入 yes**。
   - 不用語音：`bash …/show.sh --no-voice`。排練不想讓它動：`SHOW_DRY=1 bash …/show.sh`。
   - 每次都會把偵測結果錄到 `~/microduck-follow/show-<月日-時分>.jsonl`，事後可以 `--replay`。
   相機 `/dev/video0`、`--rotate 90`、自動曝光都是預設且已在 11/23 上機確認。語音用英文 GigaSpeech（預設），要先跑過 `follow/voice/setup_venv.sh`；主持人在鴨子 1 公尺內清楚地說，"LET'S GO HOME" 最容易漏，漏了就按 `h`。
5. 試一次：說 "LOOK AT ME"（頭跟著 marker 轉）→ 按 `s` 停。
6. 看最下面的狀態列：電壓、CPU 溫度。**CPU ≥ 90 °C 會自動回到待命**；上次只是站著就 84 °C，排練時用 `SHOW_DRY=1 bash …/show.sh 2>&1 | tee thermal.log` 跑 10 分鐘量溫度。

## 老闆的流程（12/03）
**以聲音為主**：老闆說英文指令，鴨子靠老闆身上的 marker 跟隨、轉頭。後台操作員拿筆電看終端機，**語音沒反應時才按鍵救場**（每一步都有對應的鍵）。

| 步驟 | 老闆說 | 操作員備援 | 鴨子 |
|---|---|---|---|
| 0. 簡報時 | （在台上講） | `show.sh` 已啟動、鴨子在側台待命 | 站著不動 |
| 1. "one more thing" | 走到鴨子前，面向它說 **"Let's go, follow me!"** | 3 秒沒動就按 `f` | 頭追 marker，一段一段跟著走上台 |
| 2. 到定位 | （停下、面向觀眾） | 停穩後可按 `g`（不按也行） | 停在老闆前面看著他 |
| 3. 撒錢槍 | **"Let's party!"**（或 "SHAKE IT"） | 開槍時現場太吵沒反應就按 `d` | 原地跳舞：左右搖、上下點、頭反向擺、嘴巴開合、笑聲叫聲；最多 30 秒自己停，回到看著老闆 |
| 4. 下台 | **"Let's go home"**（跳舞中也可以直接說） | 沒反應就按 `h` | 停舞 → 原地轉 180° → 跟著背後的 marker 下台 |

- **鴨子走得很慢，老闆要配合**：鴨子是「走一小段（≤ 2.5 秒）→ 停 → 站穩 → 看一眼 → 再走」，模擬量到的平均速度只有約 **0.07 m/s**（上限 0.12）；實機每秒只看 2 張畫面，可能更慢。走 5 公尺大約要 1 分鐘以上。建議：
  - 鴨子一開始就放在離舞台定位點近的地方（2–3 公尺內）。
  - 老闆說完 "Let's go" 走 2–3 步就停下來等，回頭看鴨子跟上（約 1.2 公尺內它就會停），再走下一段。下台也一樣。
  - 要快一點可以 `bash …/show.sh --forward 0.2`（模擬平均約 0.11 m/s）。這超過目前 0.12 的起步上限，**要先扶著實測、你同意後才用**。
- **"Let's go" 一個詞兩個意思**：鴨子在待命（台下）時，表示「跟我走」；鴨子站在台上（注視、跳舞）時，表示「回家」；鴨子正在跟著走的時候，忽略不做事。所以 "Let's go home" 就算 home 沒聽清楚也不會出錯。
- **跟著走時說 "Let's party"**：鴨子會先停下，站穩（3 秒內）就開始跳。
- **跳舞的詞用 "Let's party" 和 "Shake it"**：合成語音測試時 "Let's dance" 抓不到，只說 "dance" 又會被講稿裡的 dance 誤觸發。
- **噪音測試（合成噪音＋合成語音，11/24）**：噪音單獨放 4 分鐘（人群中英文聊天、歡呼鼓掌、音樂、撒錢槍馬達聲）**零誤觸發**，老闆講稿句子也沒有誤觸發。抓到率：
  | 說的話 | 安靜 | 人聲比噪音大很多 | 人聲比噪音大一點 |
  |---|---|---|---|
  | "Follow me" | ✓ | 全部 | 大多 |
  | "Let's go home" | ✓ | 大多 | 約一半 |
  | "Let's party" | ✓ | 約七成 | 嘈雜人聲下很差 |
  | 單獨 "Let's go" | ✓ | **抓不到** | 抓不到 |
  | "STOP" | ✓ | **很少** | 抓不到 |

  所以：上台要說 **"Let's go, follow me!"**（"follow me" 才是吵的時候靠得住的部分）；"Let's party" **在開槍前、靠近鴨子大聲說**；**緊急停止不要靠語音**，操作員手要放在 `s`／Enter 上。
  - 辨識門檻可調：`bash …/show.sh --kws-threshold 0.25`（預設 0.35；調低抓得多一點，模擬中沒有多出誤觸發，但真實現場要排練確認）。
- **語音只用合成語音測過**：要上鴨子用老闆本人的聲音試。重點是講清楚、在鴨子 1 公尺內、面向它。撒錢槍很吵，"Let's party" 最好**在開槍前說**。
- **下台轉身**：預設原地轉 180°。如果排練發現老闆不是走回原方向，改用 `bash …/show.sh --home-turn 0`：不做固定轉身，直接跟隨，靠自動對正轉向老闆（老闆要在鴨子看得到的地方）。也可以填其他角度，例如 `--home-turn 120`（正值左轉）。
- **地上的鈔票**：鴨子腳底踩到紙鈔可能會滑。下台前請工作人員清一條路，或讓老闆繞過鈔票，走得比平常更慢。
- **跳舞**全程不走路，只動身體姿態（在訓練範圍內：左右傾 0.15 rad，蹲低 1.5 cm），旁邊仍要有人能扶。按 `s` 立刻停舞、身體回正。

## 全部指令
| 主持人說 | 鍵盤備援 | 鴨子做什麼 |
|---|---|---|
| "LET'S GO" | — | 待命時 = 跟隨；注視／跳舞時 = 回家；跟隨中不做事 |
| "FOLLOW ME" | `f` | 頭追 marker；一段一段走近（每段 ≤ 2.5 秒、≤ 0.12 m/s），偏太多會先原地轉身對正 |
| "LET'S PARTY"／"SHAKE IT" | `d` | 原地跳舞（不走路），最多 30 秒；從注視或跟隨進來的會回到注視，其他回到待命 |
| "SAY HELLO" | `w` | 停下；頭看左邊觀眾＋叫一聲＋嘴巴開合，再看右邊＋叫一聲，回正；接著回到原本的模式 |
| "LOOK AT ME" | `g` | 只轉頭，不走 |
| "LET'S GO HOME" | `h` | 原地左轉 180°（`--home-turn` 可改；0 = 不轉），然後自動跟隨主持人下台。語音只在跟隨、注視、跳舞時接受 |
| "STOP" | `s` 或 Enter | 停下，站著 |
| "SIT DOWN" | `x` | 坐下 |
| "GET UP" | `u` | 從坐姿站起來（從地上起身只接受鍵盤，連按兩次 `u`） |
| "LIE DOWN" | `p` | 「趴下」：其實是最深的蹲低加前傾（robotd 沒有趴下動作），按別的鍵就回正 |
| — | `1` | 撿東西 |
| — | `2` 連按兩次 | 向前翻滾（約 1 秒，前方要淨空） |
| — | `3`／`4` 連按兩次 | 左／右踢（這台鴨子沒有踢的模型，robotd 多半會拒絕） |

坐下、站起來、趴下、技能都是「先停下再做」；做完回到待命，需要再下 `f`／`g` 才會繼續跟隨。

- 主持人走慢一點：0.12 m/s 時一段約 0.3 m，段與段之間停約 1–1.5 秒，平均約 0.07 m/s；它跟到約 1.2 公尺就停。
- 主持人要面向鴨子讓 marker 被看到；背對時（下台）marker 要在背上也貼一張，或改用鍵盤備援。
- 終端機會印出每個決策和「不可移動：原因」，操作員看著它。

## 緊急狀況
| 狀況 | 做什麼 |
|---|---|
| 走錯方向、太靠近台邊 | 按 `s`（或 Enter），或喊 "STOP" |
| 程式沒反應 | `Ctrl-C`：程式會送 stop，鴨子站著 |
| 還是在動 | 扶住鴨子，另開 SSH：`sudo systemctl stop robotd`（**鴨子會卸力倒下，一定要先扶住**） |
| 連不上 SSH | 扶住，關電源 |
| 倒地 | robotd 會自己保護，follow 自動回到待命（扶起來也**不會**自己再走）。扶好後在另一個 SSH 視窗 `python3 -m follow.stand`（會問 yes），站穩後再下指令 |
| 電池 ≤ 7.6 V | 程式自動不再走，終端機顯示「請充電」；可以繼續打招呼、轉頭 |

## 結束後
按 `q` 結束 follow（鴨子站著）；用 `show.sh` 啟動的話 mediad 會自動恢復（沒用 show.sh 才要手動 `sudo systemctl start mediad`）。
扶好後關機：`sudo poweroff`，等關機完成再斷電。

## 相機備案（直接讀相機不行時）
不停 mediad，改用瀏覽器中繼：`python3 -m follow.app --relay --voice --live`，筆電瀏覽器開 `http://<IP>:8091/` → 连接摄像头 → 勾「仅预览时启用 ArUco 识别」，分頁保持在前景。這時要靠 Wi-Fi 和這台筆電。

## 排練時要確認的待辦
- [ ] 第一次轉身前，扶著做一次小角度轉身，確認 `odom.yaw` 的正負號（反了會自己停下並說明）。
- [ ] 倒地後用 `python3 -m follow.stand` 站起來演練一次（不卸力、不重啟 robotd）；`keyboard-control.py` 退出時會卸力並停掉 robotd，不要在台上用。
- [ ] 舞台燈光下的辨識距離與曝光。
- [ ] 現場噪音下語音誤觸發；"FOLLOW ME" 誤觸發會開始走，操作員要隨時準備按 `s`。
- [ ] 下台時主持人背對鴨子：背後的 marker 看不看得到；決定 `--home-turn` 用 180 還是 0。
- [ ] 跳舞：扶著跑一次，確認左右搖的幅度不會讓它失去平衡（太大就調小 `follow/greet.py` 的 `_SWAY`）。
- [ ] 撒錢槍的聲音：會不會誤觸發語音（例如被聽成 "STOP"）；鈔票會不會擋住鏡頭。
- [ ] 老闆本人說 "Let's go!"、"Let's party!"、"Let's go home" 各 5 次，記下成功次數；講稿完整唸一遍看有沒有誤觸發。
- [ ] 跟隨距離與速度：老闆走的距離、`--forward`（預設 0.12，上限 0.30 m/s）。
